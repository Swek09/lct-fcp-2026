# ФСП · Карьера

Прототип платформы обратного найма: кандидат подтверждает квалификацию тестом,
работодатель находит подходящую категорию и направляет предложение с зарплатой.
Контакты кандидата раскрываются конкретной компании после принятия приглашения.

## Быстрый запуск

Нужен Docker с Compose. Из корня репозитория:

```sh
docker compose up --build -d
```

- Приложение: http://localhost:8080
- Документация API: http://localhost:8080/api/docs
- OpenAPI: http://localhost:8080/api/openapi.json
- Почта локального стенда: http://localhost:8025

Демоаккаунты доступны кнопками на экране входа:

| Роль | Почта | Пароль |
| --- | --- | --- |
| Кандидат | candidate@demo.fsp | DemoPass2026! |
| Работодатель | employer@demo.fsp | DemoPass2026! |

Профили, достижения и компания демонстрационные. Для проверки регистрации
создайте новый аккаунт и откройте письмо в Mailpit. Данные сохраняются в Docker volumes.
Повторный запуск не перезаписывает отредактированные профили и статусы.

## Реализовано

- Email-регистрация, подтверждение почты, вход, выход и восстановление пароля.
- Два кабинета, профиль кандидата и компании, настройки публикации профиля.
- PDF-профиль с кириллицей и локально встроенным шрифтом.
- Backend, frontend и аналитика; Junior, Middle и Senior.
- Версионированные тесты с меняющимися условиями и серверной проверкой ответов.
- История тестов, ограничение повторной попытки и смены подтверждённого грейда.
- Поиск по подтверждённой категории, фильтр стека и ФСП, объяснимое ранжирование.
- Образец теста по описанию потребности работодателя.
- Приглашения с обязательной зарплатой, статусы и раскрытие контактов после принятия.
- Короткие задания от работодателей: публикация на неделю, решения кандидатов,
  обратная связь и дата подтверждённой практики в профиле.
- Демонстрационная привязка ФСП ID и полноценный сценарий без истории ФСП.
- Адаптивный тёмный интерфейс в цветах ФСП.
- Обзор двух кабинетов, пошаговый маршрут кандидата и живая сводка найма.
- Избранные кандидаты и сравнение до трёх профилей по основаниям подбора.
- Паспорт квалификации: источник результата, дата, версия и темы реального теста.
- Публикация и редактирование вакансий, отклики, рассмотрение и отзыв согласия.

## Проверка

```sh
cd backend
go test ./...
go vet ./...
go run ./cmd/evaluate
go run ./cmd/evaluate-matching
```

Без TEST_DATABASE_URL интеграционные тесты пропускаются; порядок запуска с
настоящими PostgreSQL и Redis описан в [инструкции](docs/development.md).

```sh
cd frontend
npm ci
npm run build
```

Версии зависимостей закреплены в go.mod/go.sum и package.json/package-lock.json.

## Дальнейшая работа

Для пилота нужны экспертная калибровка заданий и грейдов и независимая
разметка качества подбора. Для сдачи подготовлены демонстрационное видео,
инструкция запуска, сопроводительный PDF и презентация. Реестр ФСП пока
представлен демонстрационными данными. LLM-провайдер
не подключён; описание потребности разбирается детерминированно.
Публикация вакансий и самостоятельные отклики реализованы. Отзыв отклика
закрывает доступ к контактам по этому отклику. План развития описан в архитектурном документе.
