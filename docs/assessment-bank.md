# Банк квалификационных заданий

Версия 2026.10-v4, 6 октября 2026. 162 доступных семейства заданий,
18 на каждую комбинацию направления и грейда. В версии v3 генератор
использовал 81 семейство; расширение добавляет 81 новое.

| Направление | Темы каждого варианта |
| --- | --- |
| Backend | HTTP, SQL, ошибки, безопасность, транзакции, расчёт нагрузки |
| Frontend | HTML, CSS, JavaScript, доступность, данные, расчёт интерфейса |
| Аналитика | SQL, метрики, статистика, качество, эксперименты, расчёт метрики |

Для Junior, Middle и Senior используются свои условия и кейсы. Backend
охватывает идемпотентность, конкурентные обновления, outbox, права на объекты,
пулы и планирование мощности. Frontend — состояние интерфейса, отмену запросов,
доступность форм и таблиц, CSS Grid, виртуализацию, SSR и бюджет загрузки.
Аналитика — SQL и оконные расчёты, очистку данных, когортные знаменатели,
взвешенные метрики, рандомизацию, интервалы и множественные проверки.

В каждой теме три семейства. Генератор выбирает два разных: 12 заданий
за 20 минут, шесть вопросов с вариантами и шесть числовых. Параметры числовых
условий и порядок ответов меняются. Операции в пределах семейства фиксированы.
Смена семейства даёт другую задачу, а не только другую перестановку ответов.

Все задания имеют одинаковый вес. Результат — целая часть от
`100 × правильные ответы / число заданий`. Порог 70 означает минимум
9/12 (75 баллов); 8/12 даёт 66 и не проходит. Тема в паспорте засчитывается
только при двух правильных ответах. Числа принимают точку и запятую;
погрешность должна быть меньше 0,005. Правило округления указано в условии.

Уже сохранённые попытки v3 проходят по исходным шести заданиям и ключам:
они не пересоздаются и не пересчитываются по новой длине. Ключ и служебный
идентификатор семейства хранятся на сервере. В preview, истории, паспорте
и OpenAPI правильные ответы не публикуются.

В `go test ./...` проверяется состав вариантов, достижимость всех семейств,
правильность оценки и совместимость старых попыток. Отдельный воспроизводимый
эксперимент: `go run ./cmd/evaluate`, [отчёт](assessment-validation.json).

Задания являются авторским стартовым банком. Независимая экспертная оценка
сложности и калибровка грейдов ещё нужны. Результат эксперимента не заменяет
проверку на реальных кандидатах и не подтверждает защиту от помощи LLM.
